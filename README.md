# 💬 chat-v003

A simple real-time chat application built with **Node.js** and **WebSockets (Socket.io)**.

This project is an experimental playground for learning and testing:

- real-time communication
- event-based messaging
- client ↔ server synchronization

🚧 **Status:** Work in progress — more features coming soon.

---

## 🚀 Tech Stack

- **Node.js**
- **Socket.io (WebSockets)**
- **JavaScript**
- **HTML / CSS**

---

## ✨ Features

- Real-time message delivery
- Multiple clients support
- Event-driven architecture
- Lightweight and fast communication

---

## 📦 Installation

```bash
git clone https://github.com/your-username/chat-v003.git
cd chat-v003
npm install
npm start
```
